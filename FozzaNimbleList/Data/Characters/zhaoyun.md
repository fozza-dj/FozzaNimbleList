## 概述

- **势力**：蜀
- **CV**：田邊幸輔（オリジンズで小野坂氏から変更）
- **武器**：龍槍（原作以来的标志性长枪）
- **主要印记**：技、雷（限界突破で力を獲得）
- **特殊系**：蜀、猛将、蜀の五虎大将（限界突破で「主君の盾」を獲得）

赵云是无双系列的招牌角色之一，蜀汉五虎大将之一。长坂坡敌中突破的经典桥段，使他在系列里享受着甚至超越关羽、吕布的"封面待遇"。本作中也是最初可操作的英杰。

## 操作时特性详解

### 忠勇兼備
- **基础效果**：印「蜀」1 つにつき攻撃力 +5%。敵を感電状態にすると、残り召喚待機時間 -1 秒。
- **强化效果**：印「蜀」1 つにつき攻撃力 +8%。（感電関連は据え置き）
- **设计要点**：蜀印数量越多收益越高，跟「蜀×10」を要求される [张飞](https://wikiwiki.jp/musoabyss/%E5%BC%B5%E9%A3%9B)的 固有戦法 相性极佳。

### 光龍神槍
- **基础效果**：感電状態の敵に対する攻撃力 +50%。連続 1000HIT ごとに、15 秒間 無双ゲージ獲得量 +50%。
- **强化效果**：上記に加え、無双バフ中の所持「雷」が +50% 扱いになる。
- **设计要点**：感電関連の強化が 2 つ重なるため、風雷ビルドでロスなく全活用できる。

> 总评：強め。蜀+風雷ビルドが本命。

## 攻击 motion 详解

### 固有动作（特殊系统）
EX 以外のチャージ攻撃の後隙をキャンセルして C1 が出せる。**ただし召喚技が出せない状況に限る**（重要）。原作にあった仕様で、初期 ver では未実装だったが ver1.4.0 で復活、ver1.5.0 で繋ぎが高速化され実用性が向上。

### 通常攻撃 (N)
払いを主体とした攻撃。N5 のみ突きで範囲が狭いが、前後の N3 / N4 / N6 は槍を振り回すため広範囲をカバーできる。攻撃速度・移動性能ともに良好。

### C1
突き。踏み込み・出の早さ・動作の短さいずれも及第点。単体でも階層の主が黄色く光ったときの差し込みに使える。固有アクションで他の C → C1 と繋ぐことで隙消し・ダメージ上乗せに使える。ver1.5.0 以降、繋ぎが高速化して実用性が増した。

### C1EX
回転多段攻撃しながら前方へジャンプ → 龍槍を叩きつけて水龍を飛ばす。ver1.4.0 でジャンプ前進力は落ちたが、水龍の攻撃判定が大きく **遠距離攻撃としても機能**。キャンセル C1 からも問題なく出せるため、あらゆる C から C1EX まで全て滑らかに繋がる。

### C2
地面打ち付け→打ち上げ衝撃波→反動でジャンプ→緩やかに落下し叩きつけ攻撃で 2 発目の打ち上げ衝撃波。原作の "飛び上がり空中行動" は、本作では叩きつけまで含めて 1 動作に統合。

### C3
龍槍を撓らせつつ回転させて 2 回連続突き → 叩きつけて広範囲攻撃〆。追加入力で突きの回数が 4 回まで増える。エフェクトは "連続突き" だが実態は "槍先を回している"（実際の槍術の動き）。

### C3EX
原作 EX を鋭くコンパクトにした突きを放ち、同時に前方の左右斜めに 2 匹の水龍を飛ばす。当初はただの突きで使いどころに困る技だったが、ver1.4.0 で水龍が追加されて範囲・射程が大幅向上、威力も連続ヒットで増加。前方の敵を一掃する性能を獲得した。

> 原作では敵を突き刺し後ドリル回転しながら高空に急上昇、各種コンボに繋げる派手な技だったが、本作には空中行動の概念が無いため大幅変更された。

### C4
1 回転しながら薙ぎ払い。シンプルな全方位攻撃。ver1.4.0 で範囲拡大＆2 ヒット化、雑魚処理性能が上昇。

### C5
スライディングしながら斬り抜け → 地面ごと抉るように龍槍を振り上げて打ち上げ衝撃波。**敵の予兆攻撃に合わせて出せば、攻撃と回避を両立できる** のが強み。

### C6
龍槍を振り回し小さい全方位衝撃波を出しつつ打ち上げ → 敵が浮いている間に演武 → 最後に石突を地面に叩きつけて水龍を Δ 状に飛ばす。**初段が出た瞬間に回避キャンセルすると演武部分を全て省略して〆だけ出せる**。カッコいいモーションは台無しになるが、撃破効率は最も良くなる。

### ダッシュ攻撃
縦回し→横払いの素早い 2 連撃。原作では槍を振り回しながら長距離を走り抜ける攻撃だったが、本作では〆の 2 連撃のみに簡略化されている。

### 無双乱舞
**「趙子龍、参る！」** ―― 三國 6 以来定番の「飛龍閃」。2 体の水龍とともに前方突進。移動距離はかなり長い。向き変更がほぼできず進路を少し曲げられるだけなので、敵の群れを縦長に捉えられるような位置・向きで撃ちたい。

### 陣形乱舞
**「龍とならん！」「喰らえ！」** ―― 三國 7 の覚醒乱舞〜真・覚醒乱舞のモーションを調整したもの。前方薙ぎ払い→左右振り回し→クロス斬り→ポーズ〆。攻撃範囲は広いが、技の要である真・覚醒乱舞部分が短く、移動距離も原作よりかなり下がっているため雑魚掃討には不向き。**階層の主の障壁破壊** が主な使い道。

### 印優先度
```
蜀 ＞ 風 ＝ 雷 ＞ 力 ＝ 技 ＝ 速
```

### 印管理のコツ
- 蜀の雷英傑は **自分と諸葛亮のみ**、召喚技まで広げても劉備と姜維だけ → わざわざ追いかける利点が乏しい
- 雷はサブの 8 に留めて **風を 16 以上** にする方が無難
- 風炎雷で **力を追求** するのも選択肢
- 技・速・雷から **真田全員と次代の担い手 6 人** は確保可能
- ピック余裕は無いので、シビアに再選出を使って必須英傑だけを揃える

## 立ち回り

| フェーズ | 戦法 |
| --- | --- |
| 序盤 | C3 / C4 中心、乱舞も積極的に撃つ |
| C6 習得後 | **C6 初段 → 回避キャンセル → 敵の群れで 2 段目** を反復、効率良く殲滅 |
| 全般 | 雑魚処理力はそれほど高くないので、召喚技 / 乱舞に依存。感電で召喚 CD が減る操作時特性がありがたい |

### 補足
- C1EX = 遠距離狙撃、C3EX = 雑魚処理 にも使えるが、**無理に「技」を集める必要はない**。属性集めを優先しよう。
  - 例外：長宗我部元親採用時は技 10 必要なので要注意
- **力 16 まで上げると C6 の殲滅力が跳ね上がり、乱戦がこの技一本で戦えるようになる**。ビルドは選ぶが価値あり。

## 英傑考察（背景）

真・三國無双シリーズでは格ゲーの三國無双時代からのレギュラー英傑。**長坂での敵中突破** が「無双」というイメージをこれ以上なく体現しているからか、呂布や関羽を差し置いてシリーズの顔・象徴とでも言うべき優遇を受けている。

- 全てのナンバリング作品の OP ムービーで主役を張っている
- 7, 8 では **パッケージも飾っている**
- 基本緑をイメージしてデザインされている蜀英傑で **唯一青白い衣装**
- 無双アビスでも **1 番最初に操作する英傑** に抜擢
- 性格も癖のない仁義に厚い好青年といった様相で、史実同様人に嫌われないキャラ付け

### 無双 OROCHI シリーズ
真田幸村と並んで三国・戦国の代表として OP で活躍したり、パッケージを飾ったりしている。無双 OROCHI 蜀編では初期から使用可能な、**実質蜀編の主役**。

### オリジンズ
長らく務めた小野坂氏から **田邊幸輔氏に CV が変更**。三国志の前半主体かつ史実重視の作劇だったため仲間入りがだいぶ遅く、三国志を詳しく知らないユーザーから驚かれていた。
